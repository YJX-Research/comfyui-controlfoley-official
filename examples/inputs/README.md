# Input Media

The repository includes representative generated examples under `examples/generated`. Those folders contain the source media, prompts, and generated outputs used for comparison.

To run the workflows with custom media, either place files in ComfyUI's `input` directory or replace the workflow paths with absolute paths.

Reference audio for AC-V2A should be 2-4 seconds. Longer audio is truncated and shorter audio is padded by the node.
